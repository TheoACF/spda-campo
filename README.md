# SPDA Campo — Aplicativo de Inspeção e Laudo Técnico (NBR 5419)

Aplicativo web progressivo (PWA) 100% offline-first para inspeção visual, medições de continuidade e aterramento, registro fotográfico e emissão de Laudo Técnico em PDF pelo celular.

## Recursos Principais
- **Edição completa pelo celular**:
  - Edite o nome do Cliente/Obra, cidade, data, equipe, aparelho e responsável técnico em **⚙ Ajustes**.
  - Adicione novos locais/blocos (`+ Local`), edite o nome de qualquer lugar/bloco (`✎`) ou renomeie cada ponto de descida (`D01`, `D02`...) e sua referência física.
- **Fotos com Câmera ou Galeria**:
  - Tire fotos direto da câmera traseira (`📷`) ou selecione da galeria (`🖼`) no BEP, em cada descida ou nas Não Conformidades.
  - Veja as miniaturas na hora, amplie em tela cheia ou exclua fotos indesejadas.
- **Dois Modos de Exportação e Envio**:
  1. **Laudo Técnico em PDF (com fotos embutidas)**:
     - **📤 Enviar PDF (WhatsApp / Salvar no Drive)**: abre o compartilhamento nativo do celular para enviar direto no WhatsApp ou salvar no Google Drive.
     - **📥 Baixar PDF no Celular**: salva o arquivo `.pdf` direto na memória do aparelho.
     - **🖨 Abrir Laudo A4 Formatado / Imprimir PDF**: visualiza o relatório em folha A4 pronta para impressão.
  2. **Pacote de Dados (`spda_dados.json` + Fotos `.jpg`)**:
     - Envia todos os arquivos originais para o Google Drive/WhatsApp ou baixa o backup JSON para importar em outro dispositivo.
